Customer
---------
id              INT                 PK
name            VARCHAR(100)
phone           VARCHAR(20)
address         VARCHAR(255)

Users
---------
id              INT                 PK
role            VARCHAR(50)
username        VARCHAR(50)         UNIQUE
password        VARCHAR(100)
created_date    DATETIME
status          ENUM('ACTIVE','INACTIVE')

Employee
---------
id              INT                 PK
name            VARCHAR(100)
phone           VARCHAR(20)
position        VARCHAR(50)
salary          DOUBLE
user_id         INT                 FK Users.id UNIQUE

Vehicle
---------
id              INT                 PK
customer_id     INT                 FK Customer.id
brand           VARCHAR(50)
vehicle_type    VARCHAR(30)
status          VARCHAR(30)
license_plate   VARCHAR(20)         UNIQUE
model           VARCHAR(50)

Service
---------
id              INT                 PK
service_name    VARCHAR(50)
price           DOUBLE
description     VARCHAR(250)

Invoice
---------
id              INT                 PK
customer_id     INT                 FK Customer.id
employee_id     INT                 FK Employee.id
total_amount    DOUBLE
issueDate       DATE

InvoiceDetail
---------
id              INT                 PK
invoice_id      INT                 FK Invoice.id
service_id      INT                 FK Service.id
service_name    VARCHAR(100)
unit_price      DOUBLE
subtotal        DOUBLE

EmployeeInvite
---------
id              INT                 PK
invite_code     VARCHAR(50)         UNIQUE
status          ENUM('UNUSED','USED')
created_date    DATETIME
